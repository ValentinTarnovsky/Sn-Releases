# Placeholders

All placeholders require [PlaceholderAPI](https://www.spigotmc.org/resources/placeholderapi.6245/) and use the `%snfourinline_` prefix. The expansion is part of the plugin and registers itself; there is nothing to download.

| Placeholder | Description |
|-------------|-------------|
| `%snfourinline_wins%` | Games won |
| `%snfourinline_losses%` | Games lost, surrenders included |
| `%snfourinline_surrenders%` | Of those losses, the ones given up: surrender, turn timeout or disconnect |
| `%snfourinline_games_played%` | Games finished |
| `%snfourinline_winrate%` | Win percentage, one decimal |
| `%snfourinline_streak%` | Current win streak |
| `%snfourinline_best_streak%` | Longest win streak ever reached |
| `%snfourinline_playing%` | `true` or `false`, worded by the `status:` block of the language file |
