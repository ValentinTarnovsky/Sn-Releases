# Placeholders

All placeholders require [PlaceholderAPI](https://www.spigotmc.org/resources/placeholderapi.6245/) and use the `%snrankperks_` prefix.

| Placeholder | Description |
|-------------|-------------|
| `%snrankperks_prefix%` | The player's custom prefix, or their LuckPerms prefix if none is selected |
| `%snrankperks_glow%` | The player's currently selected glow id, empty if none |
| `%snrankperks_chatcolor%` | The player's currently selected chat color id, empty if none |
| `%snrankperks_has_rank%` | `true` or `false`, whether the player has full access |
