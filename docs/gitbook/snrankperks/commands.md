# Commands

The root command is `/rankperks`, alias `/perks`. Running it with no arguments opens the main
menu for a player.

## Player commands

| Command | Description |
|---------|-------------|
| `/rankperks` | Open the main menu |
| `/rankperks help` | Show the help menu |
| `/rankperks toggle` | Toggle your join announcement on or off |
| `/rankperks glow` | Open the glow selection menu |
| `/rankperks glow <id>` | Set a glow directly by id |
| `/rankperks glow clear` | Clear your glow |
| `/rankperks prefix` | Open the prefix selection menu |
| `/rankperks prefix <id>` | Set a prefix directly by id |
| `/rankperks prefix clear` | Clear your prefix |
| `/rankperks color` | Open the chat color selection menu |
| `/rankperks color <id>` | Set a chat color directly by id |
| `/rankperks color clear` | Clear your chat color |

## Admin commands

| Command | Permission | Description |
|---------|-----------|-------------|
| `/rankperks reload` | `snrankperks.admin.reload` | Reload all configuration files |
