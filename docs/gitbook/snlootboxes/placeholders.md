# Placeholders

All placeholders require [PlaceholderAPI](https://www.spigotmc.org/resources/placeholderapi.6245/) and use the `%lootboxes_` prefix.

| Placeholder | Description |
|-------------|-------------|
| `%lootboxes_loaded_boxes%` | Number of loaded lootboxes. |
| `%lootboxes_active_sessions%` | Number of opening sessions currently active. |
| `%lootboxes_player_active%` | `true` when the player has an active opening session, otherwise `false`. |
| `%lootboxes_player_box%` | Id of the lootbox the player is opening, or `none`. |
