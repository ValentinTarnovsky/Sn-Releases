# Permissions

Admin nodes default to op; the basic-use node defaults to true.

| Permission | Default | Description |
|-----------|---------|-------------|
| `snenvoys.use` | true | See the countdown and claim envoys/Supply Drops |
| `snenvoys.admin` | op | Full administrative access; also bypasses the Supply Drop anti-grief protection zone |
| `snenvoys.admin.editor` | op | Allows `/envoy editor` |
| `snenvoys.admin.start` | op | Allows `/envoy start` |
| `snenvoys.admin.stop` | op | Allows `/envoy stop` |
| `snenvoys.admin.drop` | op | Allows `/envoy drop [here]` |
| `snenvoys.admin.reload` | op | Allows `/envoy reload` |
| `snenvoys.admin.debug` | op | Allows `/envoy debug` |
| `snenvoys.admin.update` | op | Receive update notifications |
