# Placeholders

All placeholders require [PlaceholderAPI](https://www.spigotmc.org/resources/placeholderapi.6245/) and use the `%snenvoys_` prefix.

| Placeholder | Description |
|-------------|-------------|
| `%snenvoys_time%` | Formatted time until the next envoy event, or a fixed "active" text while one is running |
| `%snenvoys_time_seconds%` | Raw seconds until the next envoy event, `0` while one is active |
| `%snenvoys_active%` | Number of unclaimed envoys in the running event, `0` while idle |
| `%snenvoys_supplydrop%` | Formatted time until the next Supply Drop, or a fixed "disabled" text when the feature is off |
| `%snenvoys_supplydrop_seconds%` | Raw seconds until the next Supply Drop, `0` when disabled |
